# Lavender Flash Tutorial
* We are switching for a 4.19 baseline;
* Recovery internal data its decrypted by default

## Getting Started

### Clean flash

```
1. Install last Orangefox Official Recovery, R11.1_6;
2. Wipe cache and dalvik;
3. Format data;
4. Reboot to recovery;
5. Flash the rom file;
6. Reboot to system;
```

### Dirty flash 
```
1. Download rom update;
2. Reboot to recovery;
3. Flash the rom file;
4. Wipe cache and dalvik;
5. Reboot to system and voila!
```
