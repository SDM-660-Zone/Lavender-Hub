# Lavender Flash Tutorial
* 4.19 baseline;
* Recovery internal data its encrypted by default. Decryptable using recommended recovery. 

## Getting Started

### Clean flash

```
1. Flash the rom file;
2. Install custom orangefox recovery, provided by [Sa-Sajjad](https://github.com/Sa-Sajjad);
3. Reboot to recovery;
4. Wipe cache and dalvik;
5. Format data;
6. Reboot to system;
```

### Dirty flash 
```
1. Download rom update;
2. Reboot to recovery;
3. Flash the rom file;
4. Wipe cache and dalvik;
5. Reboot to system and voila!
```
